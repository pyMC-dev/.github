# Organisation Migration Notice

The project repositories have moved from **`pymc-dev`** to **`openhop-dev`**.

## What changed

The GitHub organisation for the project has been renamed as part of an organisational update.

Project scope, maintainers, and development direction remain unchanged.

## What this means for users

Project code and development will now continue under **`openhop-dev`**.

Existing GitHub links to the previous repository locations may redirect, but users should update pinned URLs, bookmarks, scripts, documentation links, and dependency references to use the new organisation.

## What this means for contributors

Contributors should update their local Git remotes to point to the new **`openhop-dev`** repositories.

New issues, pull requests, and development activity should use the new repository locations.

## Updating your Git remote

For SSH:

```bash
git remote set-url origin git@github.com:openhop-dev/<repo-name>.git
```

For HTTPS:

```bash
git remote set-url origin https://github.com/openhop-dev/<repo-name>.git
```

## Status

* Repository migration is complete.
* Project development continues under **`openhop-dev`**.
* Documentation, tooling, and workflow references should use the new organisation URLs.

## Notes

This is an organisational migration only. Project scope and maintainers are unchanged.
