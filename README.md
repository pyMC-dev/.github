> **Organisation migration complete:** This project has moved from `pymc-dev` to [`openhop-dev`](https://github.com/openhop-dev).

This repository contains organisation-wide default community health files and configuration for **openhop-dev**.

## Updating your Git remote

If you have a local clone of any repository under the old organisation, update your remote:

**SSH:**

```bash
git remote set-url origin git@github.com:openhop-dev/<repo-name>.git
```

**HTTPS:**

```bash
git remote set-url origin https://github.com/openhop-dev/<repo-name>.git
```
